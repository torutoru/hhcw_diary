# PWA (홈 화면 앱) 기획과 설정

우리가족 웹을 안드로이드·아이폰 홈 화면에 설치해 앱처럼 쓰게 하는 작업입니다. 앱스토어 없이 웹 그대로 배포합니다.

## 1. 목표와 범위

| 항목 | 이번 범위 | 비고 |
| --- | --- | --- |
| 홈 화면 설치 (안드로이드·아이폰) | ✅ | 주소창 없는 전체 화면, 앱 전환 화면에 "우리가족" 표시 |
| 앱 아이콘·이름·테마 색 | ✅ | 아이콘은 사용자 제작본 적용 (아래 3번) |
| 설치 안내 | ✅ | 메인 피드 안내 카드(닫기 가능) + 프로필 메뉴 "앱으로 설치" |
| 새 버전 안내 | ✅ | "새 버전이 있어요 [새로고침]" — 작성 중 강제 새로고침 방지 |
| 빠른 실행 | ✅ | 화면 파일(JS·CSS·HTML·아이콘·글꼴)을 기기에 저장 |
| 오프라인 | 일부 | 화면은 뜨고 "인터넷 연결이 끊겼어요" 안내. 피드·사진은 볼 수 없음 |
| 푸시 알림 | ❌ (다음 단계) | 백엔드 작업 필요. iOS는 16.4+ & 홈 화면 설치 시에만 |
| 아이폰 시작 화면(스플래시) 이미지 | ❌ | 기기별 이미지가 많이 필요. 지금은 잠깐 배경색만 보임 |

## 2. 플랫폼별 동작

| | 안드로이드 (크롬) | 아이폰 (사파리·크롬, iOS 16.4+) |
| --- | --- | --- |
| 설치 방법 | 안내 카드·메뉴의 **[설치]** → 크롬 설치 창 | **공유 → 홈 화면에 추가** (자동 설치 창 없음, 단계 안내 시트 제공) |
| 아이콘 | manifest 아이콘 (원형 등으로 잘리는 maskable 지원) | `apple-touch-icon.png` (iOS가 모서리를 둥글게 깎음) |
| 로그인 | 브라우저 로그인 그대로 유지 | **처음 한 번 다시 로그인** (홈 화면 앱은 사파리와 저장 공간 분리). "로그인 상태 기억하기" 권장 |
| 상단 상태바 | 테마 색 `#F4F2EC` | 기본 스타일 (내용이 상태바 아래에서 시작) |
| 노치·홈 바 | — | safe-area 여백 적용 |

**카카오톡·네이버 등 앱 안 브라우저**에서는 어느 OS든 설치가 안 됩니다. 이 경우 "다른 브라우저로 열기" 안내를 보여줍니다. 가족에게 링크를 보낼 때 참고하세요.

## 3. 앱 아이콘 (사용자 제작)

원본은 [design/pwa-icons/](design/pwa-icons/)에 있고, 서비스에는 [frontend/public/icons/](../frontend/public/icons/)의 사본을 씁니다. 아이콘을 고칠 때는 **원본을 바꾼 뒤 같은 이름으로 `public/icons/`에 복사**합니다.

| 파일 | 크기 | 용도 | 규격 |
| --- | --- | --- | --- |
| `icon-192.png`, `icon-512.png` | 192, 512 | 안드로이드 일반 아이콘·설치 창 | 둥근 사각형, 모서리 투명 가능 |
| `maskable-icon-192.png`, `maskable-icon-512.png` | 192, 512 | 안드로이드 런처 (원·둥근 사각형으로 잘림) | **배경을 끝까지 꽉 채우고**, 중요한 그림은 **가운데 지름 80% 원 안**에 |
| `apple-touch-icon.png` | 180×180 | 아이폰 홈 화면 | **투명 배경 금지**(검게 보임), 모서리를 둥글게 하지 않음(iOS가 깎음) |
| `icon.svg`, `favicon-32.png` | — , 32 | 브라우저 탭 아이콘 | |

- `maskable-icon.svg`는 원본에만 두고 서비스에는 넣지 않았습니다(쓰는 곳이 없음).
- maskable 확인: https://maskable.app 에 올려 보면 잘리는 모양을 미리 볼 수 있습니다.
- 아이콘을 바꾼 뒤 이미 설치한 기기는 **앱을 지우고 다시 설치**해야 새 아이콘이 확실히 반영됩니다(특히 iOS).

| 파일 | 내용 |
| --- | --- |
| [frontend/vite.config.ts](../frontend/vite.config.ts) | `vite-plugin-pwa`: manifest(이름·색·아이콘), 서비스 워커(Workbox) 생성 |
| [frontend/index.html](../frontend/index.html) | iOS용 `apple-touch-icon`, 앱 이름, 상태바 meta |
| [frontend/src/lib/pwa.ts](../frontend/src/lib/pwa.ts) | 설치 가능 상태 판단(`useInstallMode`), 안드로이드 설치 창(`promptInstall`) |
| [frontend/src/components/InstallGuide.tsx](../frontend/src/components/InstallGuide.tsx) | 메인 피드 안내 카드, 기기별 설치 방법 시트 |
| [frontend/src/components/AppStatus.tsx](../frontend/src/components/AppStatus.tsx) | 서비스 워커 등록, 새 버전 안내, 오프라인 안내 |

### 캐시 정책 (중요)
- **저장함**: 빌드된 화면 파일, 아이콘, Google 글꼴
- **저장 안 함**: `/api/*` 응답, 사진(R2 서명 URL). 오래된 피드나 만료된 사진 주소가 보이지 않게 하려는 것입니다.
- 서비스 워커는 `/api/*` 주소 이동을 가로채지 않습니다(승인 메일 링크 `/api/signup/confirm/...`이 그대로 서버로 가야 함).
- 새 버전 확인: 앱으로 돌아올 때(화면이 다시 보일 때)와 1시간마다. 새 버전이 있으면 안내 토스트 → **새로고침**을 눌러야 바뀝니다.

### 설치 안내 판단 순서 (`useInstallMode`)
1. 이미 홈 화면 앱으로 실행 중 → 안내 없음
2. 카카오톡 등 앱 안 브라우저 → "다른 브라우저로 열기"
3. 크롬이 설치 창을 준비함 → **[설치]**
4. 아이폰·아이패드 → 공유 → 홈 화면에 추가 안내
5. 안드로이드인데 설치 창이 아직 없음 → 크롬 메뉴(⋮) → 앱 설치 안내
6. 그 밖(PC 등) → 안내 카드 없음

## 5. 확인 방법

- **로컬**: `npm run dev`(5173)에서는 서비스 워커가 동작하지 않습니다. 빌드 후 미리보기로 확인합니다.
  ```bash
  cd frontend
  npm run build
  npx vite preview --port 4173   # /api 는 로컬 백엔드(4000)로 프록시
  ```
  PC 크롬에서 http://localhost:4173 → 주소창 오른쪽 설치 아이콘, 개발자 도구 → Application → Manifest / Service Workers 확인
- **휴대폰**: 서비스 워커는 HTTPS에서만 동작해서(localhost 예외), 같은 와이파이의 `http://PC주소:4173`으로는 설치가 안 됩니다. **Netlify 배포 후** 실제 주소로 확인합니다.
- 설치 안내 카드를 닫은 뒤 다시 보려면 브라우저 저장소의 `hhcw.installCardDismissed` 값을 지웁니다.

## 6. 인프라 설정 (사용자 쪽에서 할 일)

| 대상 | 할 일 | 필요 여부 |
| --- | --- | --- |
| **사이트 주소(도메인)** | 가족들에게 설치를 안내하기 **전에 최종 주소를 정하세요.** 설치된 앱은 주소(origin)에 묶여서, 나중에 `xxx.netlify.app` → 개인 도메인으로 바꾸면 모두 **다시 설치·다시 로그인**해야 합니다. 도메인을 바꾸면 Render `APP_URL`도 같이 바꿔야 합니다. | **중요** |
| Netlify | 추가 설정 없음. HTTPS는 기본 제공, 캐시 헤더는 `netlify.toml`에 포함 | 없음 |
| Netlify (개인 도메인을 쓸 경우) | Domain management에서 도메인 연결 + HTTPS 인증서 자동 발급 확인 | 선택 |
| Render | 추가 설정 없음 | 없음 |
| Render 무료 플랜 잠들기 | 앱처럼 쓰다 보면 첫 실행 때 30초 대기가 더 답답하게 느껴질 수 있습니다. 해결하려면 유료 플랜, 또는 외부 모니터링 서비스(UptimeRobot 등)로 10~14분마다 `/api/health` 호출 | 선택 |
| Cloudflare R2 | 추가 설정 없음 (사진은 서비스 워커가 저장하지 않음) | 없음 |
| 앱 아이콘 | 제작 완료·적용됨 (`docs/design/pwa-icons/`) | 완료 |
| (다음 단계) 푸시 알림 | VAPID 키 생성 후 Render 환경변수 추가, 알림 구독 DB 테이블 | 나중에 |
